# Features

The dashboard is the daily home after onboarding. Learn filters 30 distinct lessons by level. Listening provides lesson-specific transcript content, browser TTS, speed control, sentence practice, and quiz. Speaking provides repeat-after-me practice plus MediaRecorder capture, playback, delete, re-record, graceful unsupported-browser fallback, and an optional browser Speech Recognition match check. Vocabulary provides persisted New/Learning/Familiar/Mastered review with Again/Hard/Good/Easy scheduling. Progress and dashboard metrics are derived from completed lessons and stored activity. Placement provides 28 questions with deterministic total and per-skill scores and an Estimated English Level. Settings controls daily goal, voice, speed, translation, sound, reset, export, and import.
